# 问题条件化的反事实答案排序

当前最根本的目标错位是：$P(z_i \mid Q^z. L_i,W_i,F)$ 和最终真正需要的 $P(Y_i \mid Q_i,L_i,W_i,F)$ 不是同一个任务。



TF/OE 下降的源头正是这个差异。因此我不建议继续给状态 CE 加更多补丁，而是直接把反事实约束放回真实问题和真实答案空间。

定义事实答案上下文：
$$
C_i^{a,+}
=
(Q_i,L_i,W_i,\bar F),
$$
反事实答案上下文：
$$
C_i^{a,-}
=
(Q_i,L_i^-,W_i^-,\bar F),
$$
其中严格使用你文档定义的：
$$
\bar F=\operatorname{stopgrad}(F).
$$
定义完整答案 $Y_i$ 的长度归一化对数似然：
$$
r_i(C)
=
\frac{1}{|Y_i|}
\sum_{t=1}^{|Y_i|}
\log
P_\theta
\left(
Y_{i,t}
\mid
Y_{i,<t},C
\right).
$$
希望真实答案在真实证据下比在反事实证据下更合理：
$$
r_i(C_i^{a,+})
>
r_i(C_i^{a,-}).
$$
使用最简单的 logistic ranking：
$$
\boxed{
\mathcal L_{\mathrm{QCAR},i}
=
\operatorname{softplus}
\left(
-\left[
r_i(C_i^{a,+})
-
r_i(C_i^{a,-})
\right]
\right)
}
$$


我把它称为 Question-Conditioned Counterfactual Answer Ranking，名字不重要，关键思想是：

> 不再额外训练“窗口是不是异常”；而是直接训练“原始完整答案是否真的依赖原始证据”。



### 它为什么针对性解决 TF

它使用原始 $Q_i$ 和原始 $Y_i$。

如果题干是“没有异常”，那么 gold False/True 的含义由题干自动决定，不再把 $z_i$ 错当成 True/False。完整解释也进入 $r_i$，不只强化第一个标签。





## QCAR 必须配合语义有效集合

QCAR 的必要前提是：**状态翻转后，原始 $Y_i$ 确实应该变得不合适**。

因此不能直接对所有 $\mathcal V$ 使用。定义：
$$
\mathcal V_{\mathrm{sem}}
=
\left\{
i\in\mathcal V:
Y_i\text{ 与 }z_i\text{ 语义一致，且反事实会使 }Y_i\text{ 失效}
\right\}.
$$
然后：
$$
\mathcal L_{\mathrm{QCAR}}
=
\frac{1}{|\mathcal V_{\mathrm{sem}}|}
\sum_{i\in\mathcal V_{\mathrm{sem}}}
\mathcal L_{\mathrm{QCAR},i}.
$$


- 对于 OE：答案前两句必须明确表达“有异常”或“无异常”，而且与 $z_i$ 一致；纯假设性、模糊或自相矛盾答案不进入 auxiliary。
- 不确定样本仍然保留在 $\mathcal L_{\mathrm{answer}}$ 中，只是不计算 QCAR。









---



> “问题条件化的反事实答案排序”非常适合开放题，但它不应构造一个唯一的反事实答案 $Y_i^-$。
>
> 正确做法是：固定原答案 $Q_i$ 和原答案 $Y_i$，只改变时间序列证据，要求 $Y_i$ 在真实证据下比反事实证据下更合理。



推荐的最简目标是：
$$
\boxed{
\mathcal L_{\mathrm{OE-QCAR}}
=
\frac{1}{|\mathcal V_{\mathrm{OE}}|}
\sum_{i\in\mathcal V_{\mathrm{OE}}}
\log\left(
1+\exp\left(S_i^- - S_i^+\right)
\right)
}
$$
其中 $S_i^+$ 是原答案 $Y_i$ 在真实证据下的平均 token log-likelihood，$S_i^-$ 是同一个答案在反事实证据下的平均 token log-likelihood。



但真正决定这个损失成败的不是 softplus 还是 hinge，而是以下 4 点：

1. 只能用于语义合法的 OE pair，不能只看 `counterfactual_valid`。

2. 只能对 $Y_i$ 的实际答案 token 排序，不能把 `Answer:`、EOS、padding 也计入。

3. QCAR 必须阻断 Fixed Hint 梯度，即使用 $\bar F=\operatorname{sg}(F)$。

4. 新架构必须先恢复 Baseline 回答能力，再进入联合训练；但第二阶段应当同时保留所有损失，而不是逐个损失串行训练。

 **保持与当前文件一致的符号体系**

继续使用你现有的定义：

- $X_i$：原始完整时间序列；
- $N_i$：与 $X_i$ 配对的 `normal_series`；
- $I_i=[s_i,e_i)$：当前 QA 窗口；
- $x_i=X_i[I_i]$；
- $n_i=N_i[I_i]$；
- $z_i\in\{0,1\}$：`has_anomaly`，0 正常、1 异常；
- $Q_i$：原始自然语言问题；
- $Y_i$：原始完整答案；
- $F$：Fixed Hint；
- $E_0$：冻结的 Phase-I TS Encoder；
- $L_i=E_0(X_i)[I_i]$；
- $W_i=\operatorname{Fmt}(x_i)$；
- $X_i^-$：状态与原窗口相反的完整一致反事实序列；
- $L_i^-=E_0(X_i^-)[I_i]$；
- $W_i^-=\operatorname{Fmt}(X_i^-[I_i])$。

新增的符号只有：
$$
\bar{F} = \text{sg}(F)=\operatorname{stopgrad}(F).
$$
表示 Fixed Hint 数值参与前向传播，但 QCAR 的梯度不能更新 Fixed 分支。

为避免“答案文本和 `has_anomaly` 不一致”，再定义：
$$
z_i^{(Y)}\in\{0,1,\bot\}
$$
它表示答案 $Y_i$ 在语义上声称的窗口状态：

- $z_i^{(Y)}=0$：答案明确声称正常、没有异常；
- $z_i^{(Y)}=1$：答案明确声称存在异常；
- $z_i^{(Y)}=\bot$：答案模糊、矛盾、纯方法论，无法可靠判断。

模型参数方面：

- $\Theta$：冻结 LLM；
- $\phi$：可训练的 AXIS/Perceiver/Local 映射等参数。

因此严格写法是 $P_{\Theta,\phi}$。训练时 $\Theta$ 不更新，但梯度穿过冻结 LLM，最终更新 $\phi$。



## 自顶向下下理解：QCAR 到底在解决什么问题？

### 开放题的根本困难

选择题可以监督 A/B/C/D，判断题可以监督 True/False。但开放题的答案通常是：

> 该窗口存在一个明显的向上尖峰，发生在窗口中部；随后数值快速回落，因此这更可能是异常，而不是普通波动。



开放题的答案中同时包含：是否存在异常；异常类型；方向；位置；时间演化；判断依据；自然语言解释。



所以只加入了一个 `normal / anomalous` 二分类损失，最多强化“状态判断”，不能直接保证：回答了原始问题 / 位置和方向描述正确 / 解释完整 / 答案与证据完全一致。



**另一方面，开放题的反事实答案并不唯一**。假设删除了一个 upward spike，合理的反事实答案可以有很多种：

- “窗口没有异常”
- “该窗口呈平滑变化”
- “此前的尖峰已经不存在”
- “没有足够证据将其判断为异常”

因此，硬造一个 $Y_i^-$ 会产生新的伪标签问题。



### QCAR 的核心直觉（ Question-Conditioned Counterfactual Answer Ranking）

QCAR 不问：

> 反事实输入下唯一正确的答案是什么？



它只问一个更弱、但非常可靠的问题：

> 原始答案 $Y_i$ 到底更符合真实证据，还是更符合状态已被翻转的反事实证据？



例如：

- $Q_i$：这个窗口是否存在异常？依据是什么？
- $Y_i$：窗口中部存在明显向上尖峰，随后快速回落，因此存在异常。
- 真实证据：确实有尖峰
- 反事实证据：尖峰已被正常序列替换

一个真正读取时间序列的模型应该满足：
$$
P(Y_i \mid Q_i,L_i,W_i ,\bar{F}) > P(Y_i \mid Q_i, L_i^-,W_i^-,\bar{F})
$$
如果两个概率几乎一样，说明模型可能主要依赖：

- Fixed Hint；
- 问题模板；
- 常见答案句式；
- “异常题通常怎么回答”的语言先验

而没有真正读取当前证据。



可以把它类比为法庭：

> 同一份证词 $Y_i$，在真实证据和被篡改的证据面前，哪一种情况下更可信？



QCAR 不需要编造另一份证词，只需要比较原证词与两组证据的相容性。





## QCAR 的完整数学定义

### 两个问题条件化上下文

定义：
$$
\boxed{C_i^{\text{OE,+}} = (Q_i,L_i,W_i,\bar{F})} \\
\boxed{C_{i}^{\text{OE},-} = (Q_i,L_i^-,W_i^-,\bar{F})}
$$
两者中保持不变的是：

- 原始问题 $Q_i$；
- 原始答案 $Y_i$；
- Fixed Hint 的数值 $\bar{F}$；
- Prompt 模板；
- 答案 tokenization

唯一改变的是时间序列证据：
$$
(L_i,W_i)\longrightarrow(L_i^-,W_i^-)
$$
这就是“问题条件化”的含义：比较不是在固定问题 $Q^z$ 下进行，而是在当前开放题 $Q_i$ 下进行。



### 完整答案得分：

设 $Y_i$ 被分词为：
$$
Y_i = (Y_{i,1}, Y_{i,2}, \ldots, Y_{i,T_i})
$$
其中 $T_I = |Y_i|$ 只统计实际答案内容 token，不包括：

- `Answer:`；
- BOS；
- EOS；
- padding；
- 问题结束后的分隔符

真实上下文得分：
$$
\boxed{
S_i^+
=
\frac{1}{T_i}
\sum_{k=1}^{T_i}
\log
P_{\Theta,\phi}
\left(
Y_{i,k}
\mid
Y_{i,<k},Q_i,L_i,W_i,\bar F
\right)
}
$$
反事实上下文得分：
$$
\boxed{
S_i^-
=
\frac{1}{T_i}
\sum_{k=1}^{T_i}
\log
P_{\Theta,\phi}
\left(
Y_{i,k}
\mid
Y_{i,<k},Q_i,L_i^-,W_i^-,\bar F
\right)
}
$$
因为 log-probability 通常是负数，所以：

- $S=-0.5$ 高于 $S=-2.0$；
- $S$ 越高，答案越符合当前证据。

定义排序间隔：
$$
\boxed{
\Delta_i=S_i^+-S_i^-
}
$$
理想情况是：
$$
\Delta_i>0
$$


### 最简、推荐的损失

$$
\mathcal{L}_{\text{OE-QCAR,i}} = \text{softplus}(S_i^- - S_i^+)
$$

等价于：
$$
\mathcal L_{\mathrm{OE-QCAR},i}
=
-\log\sigma(\Delta_i)
=
\log(1+\exp(-\Delta_i))
$$
它可以理解为一个 Bradley–Terry 式偏好目标：把“真实证据比反事实证据更支持 $Y_i$”看成正确偏好。



### 梯度到底在做什么

令：
$$
a_i=\sigma(S_i^- - S_i^+)
$$
则：
$$
\frac{\partial\mathcal L_i}{\partial S_i^+}
=
-a_i
$$
梯度下降时：

- 增大真实上下文得分 $S_i^+$；
- 减小反事实上下文得分 $S_i^-$。

对可训练参数 $\phi$：
$$
\boxed{
\nabla_\phi\mathcal L_i
=
a_i
\left(
\nabla_\phi S_i^-
-
\nabla_\phi S_i^+
\right)
}
$$
也就是让同一个答案对真实、反事实证据产生不同响应。

三个典型情况：

| 情况           | $\Delta_i$ | 损失             | 含义                       |
| -------------- | ---------- | ---------------- | -------------------------- |
| 模型忽略证据   | 约 0       | 约 $\log2=0.693$ | 两组证据下答案同样合理     |
| 正确 grounding | $>0$       | 小于 0.693       | 真实证据更支持答案         |
| 方向错误       | $<0$       | 大于 0.693       | 反事实证据反而更支持原答案 |



## 最关键的部分：哪些 OE 样本可以进入 QCAR

不能直接使用：

```
oe_valid = counterfactual_valid & question_type_is_oe
```

这远远不够。

你上传的 README 示例里已经出现：

- $z_i=1$，但答案说“没有明显异常”；
- $z_i=0$，但答案描述明显的突然跃迁，并认为可能漏检；
- 问题直接说“considering the presence of a local upward spike”，也就是问题本身泄露或预设了 factual 状态。

这些样本若直接用于 QCAR，会产生错误或不可满足的监督。

### OE 有效集合

定义：
$$
\mathcal V_{\mathrm{OE}}
=
\left\{
i\mid
r_i^{\mathrm{type}}
r_i^{\mathrm{format}}
r_i^{\mathrm{question}}
r_i^{\mathrm{consistent}}
r_i^{\mathrm{depend}}
r_i^{\mathrm{cf}}
=1
\right\}
$$
分别是：

### 题型正确

$$
r_i^{\mathrm{type}}
=
\mathbf 1[
\mathrm{question\_type}_i=\texttt{open\_ended}
]
$$

### 答案格式正常

$$
r_i^{\mathrm{format}}
=
\mathbf1[
Y_i\text{ 是非空的开放文本答案}
]
$$

第一版可以排除以 True/False/A/B/C/D 开头的 OE 格式漂移样本。

### 问题在状态翻转后仍然成立

$$
r_i^{\mathrm{question}}
=
\mathbf1[
Q_i\text{ 不预设 factual 状态或具体属性}
]
$$

适合：

> How would you assess whether anomalies are present in this window?

不适合：

> Considering the presence of a clear upward spike near the boundary...

因为删除 spike 后，后一个问题本身已经和反事实证据矛盾。强行训练可能教模型忽视问题前提，降低 relevance。

### 答案与 metadata 一致

$$
r_i^{\mathrm{consistent}}
=
\mathbf1[
z_i^{(Y)}=z_i
]
$$

如果 $z_i^{(Y)}=\bot$，直接跳过，不要猜。

### 答案确实依赖当前证据

$$
r_i^{\mathrm{depend}}
=
\mathbf1[
Y_i\text{ 在状态翻转后不再完整成立}
]
$$

例如纯方法论回答：

> I would inspect changes in variance and use a moving average.

它可能在 factual 和 counterfactual 下都成立，不适合排序。

而下面的回答适合：

> No anomaly is present; values change smoothly without abrupt jumps.

因为注入异常后，该结论不再成立。

### 反事实数值有效

$$
r_i^{\mathrm{cf}}
=
\mathbf1[
X_i^-\text{ 通过已有的范围、seam、donor 和状态翻转审计}
]
$$

## 第一版推荐只用高质量删除反事实

第一轮机制验证建议先使用：
$$
\boxed{
\mathcal V_{\mathrm{OE}}^{(1)}
=
\left\{
i\in\mathcal V_{\mathrm{OE}}
\mid
z_i=1,\ 
\mathrm{kind}_i=\texttt{self\_normal\_patch}
\right\}
}
$$
原因是：

- $X_i^-=\operatorname{Patch}(X_i,I_i,n_i)$；
- 不依赖 donor；
- 没有残差移植的分布和 seam 风险；
- 原异常答案在删除异常后通常会明确失效。

这不要求 pair 在状态方向上类别平衡，因为 QCAR 不是 normal/anomalous 分类。每个 pair 的监督都是“factual context 胜过 counterfactual context”。

确认机制有效后，再扩展到：

```
z_i=0 + residual_transplant
```

否则一开始同时引入 donor 质量、答案噪声和 QCAR，会再次无法判断失败来源。



## 自底向上：一个训练 step 到底发生了什么

对于一个有效 OE 样本，完整过程是：

1. 从原序列得到：

$$
L_i=E_0(X_i)[I_i],\qquad W_i=\operatorname{Fmt}(X_i[I_i])
$$

1. 从同一条完整反事实序列得到：

$$
L_i^-=E_0(X_i^-)[I_i],\qquad
W_i^-=\operatorname{Fmt}(X_i^-[I_i])
$$

1. 构造两条完全相同格式的输入，问题均为 $Q_i$。
2. 在两条输入后都 teacher-force 同一个答案 $Y_i$。
3. 只读取 $Y_i$ 内容 token 的 log-probability。
4. 得到 $S_i^+$ 和 $S_i^-$。
5. 计算：

$$
\operatorname{softplus}(S_i^- - S_i^+)
$$

1. 梯度穿过冻结 LLM，更新 Local/Perceiver/连续旁路等参数。
2. QCAR 不更新 Fixed Hint；但主答案损失仍可以更新 Fixed Hint。

这里不需要：

- 生成答案；
- 调用 G-Eval；
- 构造 $Y_i^-$；
- REINFORCE；
- 新增分类头。

Teacher forcing 的含义是：预测第 $k$ 个 token 时，模型看到真实前缀 $Y_{i,。两条分支使用完全相同的前缀，因此唯一受控变化是时间序列证据。







# 可直接移植的答案内容评分实现

下面的实现有三个重要性质：

- 复用当前 AXIS 问题模板；
- `Answer:` 作为 teacher-forced 前缀，但不计入分数；
- EOS、BOS、padding 不进入 QCAR。

```
import torch
from torch.nn.utils.rnn import pad_sequence

from .loss_redesign import (
    format_axis_question_prompt,
    memory_safe_token_nll_sums,
)


def build_oe_answer_score_batch(
    axis,
    time_series,
    questions,
    answers,
    start_indices,
    end_indices,
    window_values_override=None,
):
    tokenizer = axis.tokenizer

    if not getattr(tokenizer, "is_fast", False):
        raise RuntimeError(
            "OE answer-content masking requires a fast tokenizer "
            "with return_offsets_mapping=True"
        )

    id_rows = []
    label_rows = []

    for i, (question, answer, start, end) in enumerate(
        zip(questions, answers, start_indices, end_indices)
    ):
        values = (
            time_series[i, start:end]
            if window_values_override is None
            else window_values_override[i]
        )

        question_text = format_axis_question_prompt(
            question=question,
            start_index=start,
            end_index=end,
            window_values=values,
            num_fixed_tokens=axis.num_fixed_tokens,
            include_local=True,
            include_window=True,
            include_fixed=True,
        ).rstrip()

        question_ids = tokenizer(
            question_text,
            add_special_tokens=True,
            truncation=False,
        )["input_ids"]

        answer_text = f"Answer: {answer}"
        answer_encoding = tokenizer(
            answer_text,
            add_special_tokens=True,
            truncation=False,
            return_offsets_mapping=True,
        )

        answer_ids = answer_encoding["input_ids"]
        offsets = answer_encoding["offset_mapping"]
        content_boundary = len("Answer: ")

        # 只监督实际答案内容。
        answer_labels = []
        for token_id, (char_start, char_end) in zip(answer_ids, offsets):
            is_content = (
                char_end > content_boundary
                and char_end > char_start
            )
            answer_labels.append(token_id if is_content else -100)

        row_ids = (
            question_ids
            + [tokenizer.eos_token_id]
            + answer_ids
            + [tokenizer.eos_token_id]
        )

        row_labels = (
            [-100] * (len(question_ids) + 1)
            + answer_labels
            + [-100]
        )

        if not any(label != -100 for label in row_labels):
            raise ValueError(f"sample {i} has no answer-content tokens")

        id_rows.append(torch.tensor(row_ids, dtype=torch.long))
        label_rows.append(torch.tensor(row_labels, dtype=torch.long))

    input_ids = pad_sequence(
        id_rows,
        batch_first=True,
        padding_value=tokenizer.pad_token_id,
    )
    labels = pad_sequence(
        label_rows,
        batch_first=True,
        padding_value=-100,
    )

    lengths = torch.tensor([len(row) for row in id_rows], dtype=torch.long)
    positions = torch.arange(input_ids.shape[1]).unsqueeze(0)
    attention_mask = positions.lt(lengths.unsqueeze(1))

    return input_ids, attention_mask, labels


def oe_answer_scores(
    axis,
    local_embeddings,
    time_series,
    questions,
    answers,
    start_indices,
    end_indices,
    window_values_override,
):
    input_ids, attention_mask, labels = build_oe_answer_score_batch(
        axis,
        time_series,
        questions,
        answers,
        start_indices,
        end_indices,
        window_values_override=window_values_override,
    )

    device = axis.get_device()
    input_ids = input_ids.to(device)
    attention_mask = attention_mask.to(device)
    labels = labels.to(device)

    embeddings = axis.get_hint_embeddings(
        input_ids,
        local_embeddings,
        start_indices,
        end_indices,
        detach_fixed_hint=True,  # 对应 \bar F = sg(F)
    )

    hidden = axis.model.model(
        inputs_embeds=embeddings,
        attention_mask=attention_mask,
        use_cache=False,
        return_dict=True,
    ).last_hidden_state[:, :-1]

    nll_sums, token_counts = memory_safe_token_nll_sums(
        axis.model.lm_head,
        hidden,
        labels[:, 1:],
        chunk_size=64,
        checkpoint_chunks=True,
    )

    if bool(token_counts.eq(0).any()):
        raise RuntimeError("OE score contains an empty target")

    # S 越高越好；NLL 越低越好
    return -nll_sums / token_counts.float(), token_counts
```

然后直接依赖 DDP，因为不同 GPU 上的有效 OE pair 数可能不同。

正确的全局均值：

```
def ddp_global_pair_mean(local_sum, local_count):
    count = torch.tensor(
        float(local_count),
        device=local_sum.device,
    )

    if torch.distributed.is_initialized():
        torch.distributed.all_reduce(
            count,
            op=torch.distributed.ReduceOp.SUM,
        )
        world_size = torch.distributed.get_world_size()
    else:
        world_size = 1

    if count.item() == 0:
        return local_sum * 0.0

    # DDP 之后还会平均各 rank 的梯度，所以这里乘 world_size
    return local_sum * world_size / count


qcar_loss = ddp_global_pair_mean(
    local_qcar_sum,
    local_pair_count,
)
```
